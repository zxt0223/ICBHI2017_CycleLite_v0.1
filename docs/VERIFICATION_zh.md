## 轻量化实测

输入是一个 4 秒特征窗口，`B=1,W=1,C=4,F=64,T=401`。PyTorch 与 BLAS 线程均设为 1，预热后计时 50 次。两种宽度顺序测量；数值仅代表此次 CPU 环境。

| 项目 | 主模型，width=1 | tiny，width=0.5 |
|---|---:|---:|
| 全模型参数量 | 312,432 | 106,100 |
| 参数量，M | 0.312432 | 0.106100 |
| FP32 参数本身，MiB | 1.192 | 0.405 |
| Conv/Linear MACs，百万 | 104.70 | 38.02 |
| 模型推理中位耗时，ms | 12.41 | 6.24 |
| 音频前端中位耗时，ms | 8.93 | 8.20 |

MACs 没有计入 STFT/PCEN、激活、归一化、池化和注意力矩阵乘法，因此不能直接当成完整系统 FLOPs。推理延迟不包括文件读取、重采样和分窗；前端使用合成的 16 kHz 音频，不是任意采样率的全路径测试。长周期的骨干计算量随窗口数增长。
