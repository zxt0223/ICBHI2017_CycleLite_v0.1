# 硕士课题研究路线与贡献边界

建议题目：**面向呼吸音异常识别的事件结构约束轻量神经网络研究**。

本工程的定位是智能辅助诊断系统中的声学识别模块。先完成可信的四分类算法研究，再根据课题要求增加采集、周期检测、可视化与部署系统。当前版本没有真实训练成绩，不能据此宣称课题已经完成。

## 1. 目标应当同时约束效果和成本

| 维度 | 建议预先登记的目标 | 当前证据 |
|---|---|---|
| 任务 | normal/crackle/wheeze/both 四分类 | 已实现、评分测试通过 |
| 协议 | 官方 train/test，开发阶段患者隔离验证 | 已实现清单审计；待接入真实清单 |
| 效果 | 最终官方测试 Score 均值超过 60%，3–5 seeds | 尚无真实测量，不能保证 |
| 参数量 | 主模型不超过 0.5M | 实测 0.312432M |
| 计算量 | 与同任务基线、相同输入长度对比 | 提供 profiler；尚无真实基线对照实验 |
| 部署 | 单一学生模型；报告端到端延迟与内存 | 已实现模型导出，尚未测目标设备 |
| 方法贡献 | 有清楚的问题、机制及独立消融证据 | 候选机制已实现，贡献尚待证实 |

不建议把“某一次 seed 超过 60”作为唯一成功条件。更有说服力的结果是：相同患者划分与训练预算下，多 seeds 均值提升，少数类表现改善，参数/延迟下降，并提供配对患者 bootstrap。超过 60 的均值不代表其置信区间下界也超过 60。

进一步查新关键词应包括 `respiratory sound multi-resolution PCEN`, `crackle wheeze anisotropic convolution`, `multi-label attention respiratory cycle`, `weakly supervised event pooling`, `lightweight respiratory knowledge distillation`。检索要覆盖论文正文、最近年份和代码，而不只看题目。导师认可、系统查新与实证结果共同决定能否构成硕士论文贡献。

## 3. 本项目的三个候选研究问题

### 候选 A：不同时间尺度的异常事件如何在小模型中保留？

问题：爆裂音具有短时瞬态特征，哮鸣音具有较持续的窄带结构。只用一种时间分辨率可能顾此失彼。粗暴裁剪、时间拉伸或过强去噪也可能改变判别线索。

实现：32 ms/128 ms 两种窗长，共享 10 ms 时间步。每种生成 log-Mel 与 PCEN，组成 4 通道，送入一个共享主干。较小窗长提供时间细节，较大窗长提供频率细节，log 与 PCEN 保留互补的压缩形式。按完整标注周期算特征，再分窗聚合，避免只取一个随机片段导致弱标签错配。

**候选贡献是面向两类声学结构的组合设计和验证，不是发明 STFT、Mel 或 PCEN。** 必须对照单分辨率、双 log、双 log+PCEN，并统计 crackle/wheeze/both 的 recall 变化。增加 2k/4k 上限或高通关闭实验时，应改 frontend 配置并建立新缓存，不能复用旧特征。

假设可能被否定：PCEN 也可能削弱持续哮鸣音的有用能量差异，多通道可能冗余。若验证集没有稳定收益，去掉该模块更合理。

### 候选 B：用方向性深度卷积表达事件形态，控制部署成本

每个主干块先用 1×1 卷积扩展通道，然后并行使用频率×时间为 7×3、3×7 的深度卷积。门控根据有效特征的汇聚结果，为两个分支产生每通道权重，最后通过 1×1 投影融合。宽频/短时与窄频/持续的形态是设计动机，不是强行指定某个分支只能识别某类事件。

默认通道序列为 24→32→48→80→128，每个阶段两块；总时间下采样约 8 倍。选择这些宽度是初始工程设定，尚未做架构搜索。

**方向卷积、深度可分离卷积和门控都有大量先例。** 本课题需要证明该配置在相同任务和预算下优于普通深度卷积，而不能只比较一个很大的旧模型。应补充参数量接近的普通卷积对照；目前提供的 baseline 容量不同，不能仅凭其胜负归因所有收益。

宽度 0.5 / 1.0 / 2.0 支持准确率与成本曲线。最终部署只选择预先固定的一种单模型，避免用大集成的成绩搭配小模型的参数量。

### 候选 C：让四分类结果与两个事件的存在性保持一致

主干在每个窗口产生时间特征，把一个周期所有窗口的有效时间 token 合并。学习两个查询，对应 crackle 和 wheeze；分别在有效 token 上做注意力汇聚，得到 `h_C` 和 `h_W`，同时计算全局均值 `h_G`。主分类头使用三者拼接，输出四分类概率。

设主头概率为 `p_N,p_C,p_W,p_B`，两个辅助头分别输出 `q_C,q_W`。联合损失为：

\[
L=L_{CE}^{weighted}
 +\lambda_e\,BCE((q_C,q_W),(c,w))
 +\lambda_m\,MSE((q_C,q_W),(p_C+p_B,p_W+p_B)).
\]

默认 `lambda_e=0.3, lambda_m=0.1`，都必须经训练内部验证。主损失采用平方根逆频率权重，不同时叠加全均衡采样器以免过度补偿。另有按官方 Score 的 normal/全部 abnormal 数量设计的 CE 权重消融；它是损失代理，不是直接优化不可微的最终 Score。

这一设计让“both”可共享两种事件的统计线索，并让主头边际概率与辅助头一致。是否提高 both 的召回与稳定性是可验证假设。辅助头只做训练约束与可选研究输出，不改变四分类 argmax 评估口径。

**多标签、注意力和一致性正则均已有相关研究。** 本组合的独特性需要与 Chua/Cheng 等工作逐项比较，可能最终只能支撑一种应用改进而非独立理论创新。注意力图也不能直接当作真实事件定位标注；本数据只提供周期级事件标签。

## 4. 蒸馏的位置

蒸馏是提高部署学生性能的可选训练手段，不列为首要创新。当前可运行实现是同前端的宽模型→轻量模型，温度 3，KL 权重 0.3；教师和学生处理同一份增强输入。

优先检查教师验证质量。教师较差时，学生可能被拖累。若从零训练仍不足，下一阶段优先考虑合法来源、符合患者隔离协议的 AudioSet 预训练教师或轻量预训练基线。已有文献表明这条路线值得研究，但不能从文献收益推导本项目一定达到 60。

将来接入 AST/CLAP/EfficientAT 时必须保留各自真实前端；不应为了接口统一擅自更改其采样率、输入范围或归一化。如果教师在全部官方训练患者上训练过，而学生要在其中一部分患者上验证，就已经泄漏，应重训教师或采用严格患者折外教师方案。

## 5. 最低可交付实验矩阵

| 实验 | 主要问题 | 主要输出 |
|---|---|---|
| B0 单 log+普通深度卷积+均值聚合 | 可复现起点 | Sp/Se/Score、4 类 recall、参数和 MACs |
| B1 B0+双分辨率 log/PCEN | 前端是否有效 | 同上；尤其 C/W 的变化 |
| B2 B1+方向性卷积 | 形态建模是否值得其成本 | 同上；计算量匹配对照 |
| B3 B2+双事件聚合 | 完整周期事件汇聚是否有效 | both recall、长/短周期分组 |
| B4 B3+辅助事件+一致性 | 结构约束是否改善泛化 | 多 seeds 均值与标准差 |
| B5 B4 去 PCEN/去一致性 | 每个组件是否真正必要 | 独立移除消融 |
| B6 0.5/1.0/2.0 宽度 | 效果与成本权衡 | Score–Params/MACs 曲线 |
| B7 教师蒸馏学生 | 训练成本能否换取部署收益 | 单学生结果及教师成本单列 |
| E1 原始/噪声/频响扰动 | 鲁棒性 | 不同 SNR、不同设备分组 |
| E2 公认外部基线 | 与已有工作竞争是否公平 | 至少 CNN6 或小型 AudioSet 预训练 CNN |

B0–B7 的核心训练配置已提供。E1 扰动评估、E2 外部基线适配、参数匹配搜索与自动事件定位是后续研究工作，当前代码未实现这些实验，不应在论文中写成已完成。

开发阶段固定患者划分 seed=42，至少训练 seeds 1/2/3；资源允许时使用 1–5。协议固定之后才能做官方测试。若要评估开发患者划分敏感性，可另建不同 `split-seed` 的缓存，清楚标为内部稳健性实验，不能挑最有利的测试结果。

## 6. 如果没有达到 60，如何定位

| 验证现象 | 优先排查 | 合理动作 |
|---|---|---|
| Sp 很高、Se 很低 | 模型偏向 normal，少数事件线索弱 | 看各类 recall；比较 sqrt/score 权重和事件损失 |
| Se 上升、Sp 严重下降 | 过度补偿异常类别 | 降低类别加权或辅助项；不在测试集调阈值 |
| train loss 下降、val 长期变差 | 患者/设备过拟合 | 减小宽度、调正则；核查设备分布 |
| both 几乎全错 | 最少类不足、两事件表征混淆 | 检查边际一致性与辅助任务消融 |
| 长周期差 | 异常证据被均值稀释 | 对比事件汇聚与均值；检查窗口/注意力 |
| 短周期差 | 补零、边界与归一化影响 | 查看持续时间分布，补充更短窗口消融 |
| 无预训练模型普遍不足 | 数据量小、迁移特征缺失 | 接入可靠的音频预训练竞争基线/教师 |
| 各模块都无稳定收益 | 研究假设可能不成立 | 保留简单版本，调整问题定义并继续查新 |

不要为了达到 60 而把患者随机拆到两个集合、改变四分类评分、筛选最幸运 seed、只报告最有利设备或把测试集用作验证。当前代码直接阻止了其中一部分错误；科研协议仍需要实验者遵守。

## 7. 局限与当前实现细节

- 主干 BatchNorm 在有效窗口内部仍会受到补零区域比例影响；补零被屏蔽出最终注意力与均值聚合，不能据此宣称所有内部统计完全不受 padding 影响。
- PCEN 在每个周期首帧初始化，短周期和跨设备效果需要验证；不是端到端可训练前端。
- 时间下采样后 attention 的分辨率约 80 ms；不能直接当作毫秒级爆裂音检测器。
- 4 秒重叠窗口使计算量依赖周期长度；网络参数少不代表任意长录音都有固定成本。
- 原始音频与 float16 缓存的推理路径做了统一，并验证概率一致；真实数据中的特殊 WAV 编码或标注异常还需检查。
- 多 seed 方差、患者 bootstrap 区间、跨设备泛化反映不同不确定性，应分别报告。
- 导出的是特征到 logits 网络；尚无自动周期检测、手机 App、INT8、临床校准或临床验证。

## 8. 论文组织建议

1. 绪论：呼吸音辅助分析的任务、困难、轻量化需求与贡献界限。
2. 数据与方法基础：四分类定义、官方协议、数据不均衡、声学事件与已有研究。
3. 事件保留预处理与轻量结构：问题、数学定义、结构、训练目标和复杂度。
4. 实验：严格划分、对比、逐项消融、多 seeds、错误分析和鲁棒性。
5. 系统与部署：真实设备的采集/周期分割/推理流程及资源测量，仅写已实现内容。
6. 总结与展望：实验支持的结论、未解决的泛化问题和适用范围。

可以先写方法与实验设计；结果表应保留“待实验”。是否完成论文贡献，需要真实训练、可复现实验记录和导师反馈，不能由本代码包预先保证。
